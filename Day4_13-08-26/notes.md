### Lists and Tables

##### **1. Lists**



###### HTML provides two main types of lists:



###### **Ordered List <ol>:**

###### 

* Displays items in a specific order.
* <li> is used for each list item.
* type can be used to change the numbering style.
* start specifies the starting number.
* reversed displays the list in reverse order.





###### **Unordered List <ul>:**



* Displays items using bullets.
* <li> is used for each item.
* type can be disc, circle, etc.



###### **Nested List:**



A list can be placed inside another list.



#### 2\. Tables



Tables are used to display data in rows and columns.



###### Important tags:



<table> – creates a table.

<thead> – contains the table heading.

<tbody> – contains the table data.

<tr> – creates a row.

<th> – creates a heading cell.

<td> – creates a data cell.
