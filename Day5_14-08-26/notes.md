### iframe, Video and Audio:

#### 1\. <iframe> Tag

* <iframe> is used to embed another webpage or content inside an HTML page.
* src specifies the content to display.
* width and height define the size.



Example:



<iframe src="URL" width="600" height="450"></iframe>

#### 2\. <video> Tag

* Used to add video to a webpage.
* <source> specifies the video file and its type.



Ex:



<video controls>

&#x20;   <source src="movie.mp4" type="video/mp4">

</video>

### 3\. <audio> Tag

* Used to add audio to a webpage.
* controls provides audio controls.
* <source> specifies the audio file.



Ex:



<audio controls>

&#x20;   <source src="audio.mp3" type="audio/mpeg">

</audio>
