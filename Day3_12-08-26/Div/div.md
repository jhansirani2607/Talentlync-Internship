## <div> Tag

* ##### <div> stands for Division.
* ##### It is used to group HTML elements together.
* ##### It is a block-level element.
* ##### We commonly use <div> to create different sections of a webpage.
* ##### CSS can be applied to a <div> using class or id.    
* ##### for example :header section ,footer section,side bar section etc in web page.
