# Registration Form 



Created a Registration Form using HTML.



##### HTML Concepts Used

* ###### <form> – creates a form.
* ###### <label> – displays the field name.
* ###### <input> – takes user input.
* ###### type="text" – accepts text.
* ###### type="number" – accepts numbers with min and max.
* ###### type="radio" – allows selecting one option.
* ###### <select> and <option> – creates a dropdown.
* ###### type="checkbox" – allows selecting multiple options.
* ###### type="email" – accepts an email address.
* ###### type="password" – hides the entered password.
* ###### type="tel" – accepts a mobile number.
* ###### <button> – creates buttons.
* ###### placeholder – displays hint text inside an input.
* ###### name – groups radio buttons and identifies form fields.
