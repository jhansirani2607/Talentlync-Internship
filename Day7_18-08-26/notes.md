### Local Storage



Local Storage is used to store data in the user's browser.



In Local Storage:



* setItem() – used to store data.
* getItem() – used to retrieve stored data.
* removeItem() – used to remove a particular item.
* clear() – used to remove all stored data.



Example:



localStorage.setItem("Name", name);

localStorage.getItem("Name");



Local Storage data remains available even after closing and reopening the browser, until it is removed or cleared.



### Session Storage



Session Storage is also used to store data in the browser, but the data is associated with the current browser tab/session.



setItem() – stores data.

getItem() – retrieves data.

removeItem() – removes a particular item.

clear() – removes all session data.
